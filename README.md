# SMM Agent

Сервис ведёт тематическую новостную ленту. Владелец задаёт тему, аудиторию и правила канала. Агент собирает материалы, объединяет сообщения об одном событии и публикует важное сразу, а менее важное выпускает из свежего резерва в затишье.

Бэкенд на Go состоит из HTTP API и фонового worker. PostgreSQL хранит каталог источников, настройки, материалы, карточки событий и публикации. API обслуживает встроенную панель и ленту сайта. Worker собирает и обрабатывает материалы, готовит версии и доставляет их на выбранные площадки.

## Локальный запуск

```powershell
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
docker compose up --build --wait
Invoke-RestMethod http://127.0.0.1:8180/api/ready
```

Панель доступна на [127.0.0.1:8180](http://127.0.0.1:8180/). [Инструкция по запуску](docs/backend-local.md) показывает, как добавить источник, включить канал и проверить конвейер.

- [Документация](docs/README.md) описывает узлы проекта и путь данных от источников до публикации.
- [Структура репозитория](docs/structure.md) показывает назначение папок.
- [OpenAPI](api/openapi.yaml) описывает маршруты и форматы запросов.
