# Правила работы с репозиторием

При каждом изменении логики или кода в том же наборе правок обновляй соответствующий файл в `docs/`. Сверяй документацию с итоговой реализацией перед завершением задачи.

- Опиши, что изменилось во входных данных, обработке, выходе и переходе данных между компонентами. Если затронуты хранилище, состояния, ошибки, конфигурация или порядок запуска, обнови соответствующие разделы.
- При изменении API синхронизируй `api/openapi.yaml` и документ управления. При изменении схемы PostgreSQL обнови описание таблиц, связей и миграций. При добавлении компонента обнови карту репозитория и схему потоков.
- Проверь команды и относительные ссылки, которых коснулись правки. Фиксируй текущее поведение по коду, а запланированные функции обозначай явно.

Оглавление и ссылки на тематические документы находятся в [docs/README.md](docs/README.md).
